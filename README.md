Shopping Cart

Version: 5113b52715be4c01a8f6db83d38b8d75ee924c88

Requirements
	•	Node.js 20+
	•	npm

Setup:

Install dependencies: npm install

Run Tests: npm test

Build: npm run build

Notes:
- The solution is implemented using TypeScript.
- All totals are rounded to 2 decimal places as required.
- Monetary calculations are handled using 100 multiplier internally to avoid floating-point precision issues.
- The project follows a test-first approach (TDD).
- Each step of the exercise is marked using git tags (step-1, step-2, step-3).
